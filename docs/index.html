In detail

Each change, with a snapshot.

Scalable booking pickers new

The New / Edit Booking dialog no longer renders your entire roster as toggle chips. People and Instruments are dropdowns; picking one drops a removable badge above the list and shrinks the menu.

  • A small × on the left of each badge removes it.
  • Hover a person badge for their role; an instrument badge for its modality.
  • Notes are a rich-text editor (see below); the old Meeting Link field is gone — paste links into notes.

Register Person & Department new

Register a researcher from the standard form — now with separate Lab / Group and Department dropdowns instead of one comma-packed field. Each dropdown has a “+ Add New” mini-dialog for values you don’t have yet, and the inline avatar is small and gender-neutral.

  • From the booking dialog, the mint Register New Person button opens this form and drops the new person straight into the picker — add several in a row.
  • Department shows as its own column in People and its own field in every export.

People directory, wider & wrapped changed

The People, Labs & Researchers table gains a Department column and lays out fully within the window — no horizontal scrollbar. Long values wrap; the row actions stay pinned.

“+ Add New” everywhere changed

Lab / Group, Department, and the vocabulary dropdowns (Modality, Funding, Sample, Role) all share the same pattern: a select of known values plus a “+ Add New” button that opens a small dialog and injects your new value, selected, back into the form.

Nested dialogs now close the topmost one on Cancel / Save — so registering a new lab never dismisses the form underneath.

Rich-text meeting notes new

Meeting notes support light formatting in the app’s own font: bullet lists, bold (Ctrl/⌘+B), italics (Ctrl/⌘+I), and preset sizes (Small / Normal / Large / Huge).

  • Formatting is preserved in Word (.docx) and PDF exports; Excel / CSV get clean plain text.
  • Stored as a safe HTML subset; legacy plain-text notes still display correctly.

Guided tour walks every dialog changed

The walkthrough grew from a screen tour into a full 19-step guide that opens each real dialog — New Project, Add Milestone, Custom Field, Attach File, Register Person, Add Instrument, New Booking, and Today’s Agenda — so you see the actual forms. Steps glide with a soft cross-fade instead of a hard cut; each one spotlights a stable, precise target and always scrolls it into view first; a Back button lets you revisit an earlier step; and any dialog a step opens is dismissed automatically when you move on.

Take the tour yourself

Open the app and click Tour in the sidebar — it now opens every dialog for you. Everything runs locally in your browser; nothing is uploaded.
