Bookings grow up: instruments and core staff now get a start/end time, double-booking the same instrument or person is blocked outright, and every booking computes a live bill of materials — instrument and staff cost, a standing lab discount, overhead, and tax — down to a final total. In detail

Each change, with a snapshot.

Timed instrument & core-staff bookings new

The New / Edit Booking dialog gains Start Time and End Time alongside the date, plus a brand-new Assign Core Staff picker — separate from the plain attendee list — for the facility staff who actually run the session and get billed for it.

  • Core Staff options are anyone flagged “Core Staff” on their profile, with an hourly rate.
  • Times are optional — a booking with no times still behaves like a plain meeting.

Double-booking is blocked, not just discouraged new

Save a booking whose time window overlaps another booking on the same instrument — or the same core-staff member — and the save is rejected outright, with a toast naming exactly which booking it clashes with.

  • Checked independently for every selected instrument and every selected staff member.
  • No override: a facility has exactly one of each instrument, and a person can’t be in two places.

A live cost & time breakdown, right in the booking new

Every instrument and core-staff line updates as you build the booking: instrument cost by the hour (or by an amount you type, for per-unit / per-weight pricing), staff cost by hourly rate with a one-hour minimum, then a standing lab discount plus overhead and tax rolled up into a final total.

  • Staff billing floors at 1 hour and rounds up — 10 minutes bills as 1 hour, 65 minutes as 2.
  • Discounts apply to time-billed instrument cost only, never to staff time.

Group discounts, an admin override, and facility-wide billing rates new

Settings gains a Billing Rates card (internal / external overhead %, tax %, currency) and an Admin Mode switch that reveals a per-lab Group Discounts editor plus a manual per-booking override. This app has no accounts, so Admin Mode is a local convenience toggle — not real access control.

  • A lab’s standing discount auto-applies to any booking under a project whose PI belongs to that lab.
  • Both the group and manual discount show up, live, in the booking’s cost breakdown.

Project Costs, and richer exports new

Every project page now lists its bookings with their stored subtotal, pre-tax, and final totals — snapshotted at save time, so re-pricing an instrument later never rewrites a past invoice. Instrument cost/unit and staff rate now flow through to XLSX/DOCX/PDF, and the facility-wide export gains a dedicated Bookings & Costs sheet.

Custom project statuses new

Project status is no longer a fixed five-item list — it’s the same “+ Add New” vocabulary pattern used everywhere else in the app, seeded with a review → kickoff → billing workflow (Submitted for review, Under review, Kickoff scheduled, Invoiced, Paid) so a facility can track a lab’s request from submission through payment.
