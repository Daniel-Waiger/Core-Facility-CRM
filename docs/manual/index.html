Core Facility Tracker

User Manual

This manual explains every screen in Core Facility Tracker — from opening the app for the first time to reading a billing report — in plain language. No prior experience with the app, or with project-tracking software in general, is assumed: every term is defined the first time it matters, and every rule comes with a plain-English reason for why it works that way. Read the chapters in order if you're brand new, or jump straight to what you need with the search box or the quick-task list below.
